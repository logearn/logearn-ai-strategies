# review 工具 · 功能梳理与改进建议（按优先级）

> 目的：现在 7 个 tab 里"找因子"这一步被拆到 3 个并列 tab、同一件事有 7 个入口，认知负担重、口径不完全一致。本文按优先级列出**去掉/合并/改进**建议，先评审、后实施。

## 0. 主线（tab 应该服务的流水线）

```
数据切片(训练集/基准库) → 找因子(哪些字段/区间能区分高倍) → 阵营库收藏
   → 策略调参(北极星：score↔returnMax 的 spearman ρ) → 基准库样本外验证 → 字段维护
```

理想状态：tab 顺序 = 这条主线；每一步一个 tab，不重复。

## 1. 逐 tab 现状与评级

| Tab | 面板 | 评级 | 一句话 |
|---|---|---|---|
| 数据与过滤 | 数据源+切片 / 全局过滤&筛选CA / 总览统计 / 快照速查 | ✅ 核心 | 刚重构完，训练集/基准库为主体 |
| 相关性与显著性 | 相关性排行(r/ρ/p) · AUC · 字段体检(波峰+VIF) | ⚠️ 改 | 线性 r 对右尾数据误导；AUC/波峰才是对口径 |
| 图表 | 字段矩阵热力 · 分箱柱状 · 散点图 | ⚠️ 精简 | 矩阵热力低信号建议去掉；散点保留 |
| 阵营库 | 收藏打分因子+分组+高倍落点校验 | ✅ 核心 | — |
| 策略 | 策略回放全套 · 批量对比 | ✅/⚠️ | 回放核心；批量对比建议去掉 |
| 回测·因子 | 自动挖区间+lift+捕获率+生成策略 | ✅ 核心 | 是"找因子"的超集 |
| 字段 | 自定义字段 · 字段浏览 · 标注管理 | ✅ 保留 | 可把快照速查并进来 |

## 2. 三个核心重叠（要解决的根因）

1. **"字段→倍率有没有信号"有 7 个视角**：相关性排行、AUC、波峰扫描、分箱柱状、散点、矩阵热力、回测·因子。其中**回测·因子（FactorLab）已是超集**（挖区间 + lift + 捕获率 + 样本外 + 直接生成策略），其余多是它的弱化重复。
2. **"某字段最佳区间"算了 3 遍**：字段体检的波峰、回测·因子、阵营库的高倍落点校验——三处独立实现，口径可能不一致，用户不知道信哪个。
3. **线性相关系数 r**：对 meme 极端右尾分布系统性误导（一个 100x 就能把 r 拉飞）。应以 AUC / Spearman ρ / 波峰(非单调) 为准——工具自身注释早已指出这点。

## 3. 建议清单（按优先级）

### P0 · 低风险高收益（建议先做）

- **P0-1 去掉「字段矩阵热力表」**（图表 tab / MatrixTable）
  - 理由：热力图对右尾数据低信号、占屏，相关性表 + 散点已覆盖同类信息。
  - 影响面：仅图表 tab；无数据/逻辑依赖。风险：低。

- **P0-2 去掉「批量对比」**（策略 tab / ComparePanel）
  - 理由：它要"再上传一组文件做对照"；现在有了切片（训练集/基准库），样本外对照应走**基准库**，这个入口已被取代，且和"数据源"逻辑割裂、易造成两套数据来源。
  - 影响面：策略 tab 末尾一块；独立组件。风险：低。
  - 备选：不删，改造成"对照 = 基准库切片"。

### P1 · 中等改动（收敛口径）

- **P1-1 相关性排行弱化线性 r**
  - 做法：砍掉/隐藏线性 r 列，保留 Spearman ρ；或整个「相关性排行」并入「字段体检」。
  - 理由：线性 r 误导；ρ/AUC/波峰才可靠。风险：中（改表结构）。

- **P1-2 统一"最佳区间"口径**
  - 做法：波峰扫描、回测·因子、阵营库高倍落点校验共用同一套区间算法（阵营库校验已用 `findHotInterval`，让另外两处也走它）。
  - 理由：消除"三处算出不同区间、不知信哪个"。风险：中。

- **P1-3 快照速查并入「字段」tab**
  - 做法：SnapshotInspector 从"数据与过滤"挪到"字段"，和字段浏览放一起（都是"看字段/值"）。
  - 理由：功能同类、减少"数据与过滤"tab 拥挤。风险：低（纯挪位）。

### P2 · 大改（结构重排，评审后再定）

- **P2-1 三个"找因子"tab 合一**
  - 做法：把「相关性与显著性」+「图表」+「回测·因子」收敛成一个 tab（如"找因子"），以 FactorLab 为主体 + 散点复核 + AUC/波峰，去掉重复视角。tab 从 7 → 5~6，与主线一一对应。
  - 理由：这三者本是同一步骤的不同视角。风险：较高（大范围 UI 重排），建议 P0/P1 完成后再做。

- **P2-2 找因子时直接显示"进打分池后对 ρ 的边际贡献"**
  - 做法：候选因子旁给出"加入策略后 score↔returnMax 的 ρ 变化"，而不只是单字段指标。
  - 理由：北极星是 ρ，找因子应直接对齐它。风险：中高（要接策略回放的评估）。

---

## 4. 建议执行顺序

1. 先做 **P0-1 + P0-2**（两个删除，低风险，立刻减负）。
2. 再做 **P1-1 / P1-2 / P1-3**（收敛口径与归位）。
3. 评审后再决定 **P2**（结构重排，改动大）。
