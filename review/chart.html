⚙️ 自定义组装字段（JS）

用 JS 代码自己组装新字段：f 是当前行全部扁平化字段（如 f['pool_liquidity']），row 是行元信息（row.returnMax / row.returnCurrent / row.symbol / row.token_address）。支持单表达式（如 f['mcap'] / f['pool_liquidity']）或带 return 的函数体。返回有限数值才会写入该行，返回 null/undefined/NaN 视为该行无值。后定义的字段可以引用先定义的自定义字段。定义保存在浏览器本地（localStorage），刷新不丢失。

🔒 Pro 分析

解锁后可用：相关性矩阵热力图、分组对比分析、多元回归特征重要性、时间维度分析、分类字段箱线图。

1. 相关性矩阵 / 热力图

选中若干字段，查看两两 Pearson r 热力图，快速发现高度共线的字段（避免把两个高度相关的字段都当成独立的"强特征"）。

2. 分组对比分析

按分类字段（如 signalType/platform）分组，对比同一特征在不同组内与收益的相关性是否一致，避免"整体相关性显著，其实只是某一类信号驱动"的伪相关（辛普森悖论）。分组字段也可以是数值字段，填写断点后会自动离散化分组。

分组样本数均值胜率与目标的 rp

3. 特征重要性（多元线性回归，标准化系数）

选择目标和若干特征，对标准化后的数据做普通最小二乘（OLS）回归，系数反映"控制其他变量后该字段每变化 1 个标准差对目标的独立贡献"，比单变量 r 更能剔除共线字段的虚假重要性。注意：字段间高度共线时系数会不稳定，建议先用上方相关性矩阵排查。

字段β（标准化系数）单变量 r（对照）VIF共线性

4. 时间维度分析

按开仓时间（swap_begin_time）分桶，查看胜率/均值/与特征的相关性是否随时间漂移，判断策略是否随市场环境变化而失效。

时间段样本数胜率均值与特征的 r

5. 分类字段与收益关系

按分类字段（如 signalType/platform）分组，展示目标数值字段的箱线图分布 + 胜率对比表，专门分析分类变量而不是只用它做散点图颜色。分类字段也可以是数值字段，填写断点后会自动离散化分组。
